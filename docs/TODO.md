# Day2 — План разработки

Правила работы с файлом: задачи выполняются по порядку этапов; выполненное отмечается `[x]` в том же коммите, что и код; новые задачи добавляются в соответствующий этап, а не в конец. Каждый этап завершается работающим инкрементом (критерий готовности — в заголовке).
