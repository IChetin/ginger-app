Реализация тем

Обе темы — на CSS-переменных. Дефолт по системе через prefers-color-scheme, ручное переопределение — атрибутом data-theme на <html>, выбор сохраняется. Tailwind настроить на чтение переменных (bg: 'var(--bg)' и т.д.), чтобы классы работали в обеих темах без дублирования.

/* globals.css */
:root { /* dark-токены */ }
@media (prefers-color-scheme: light) {
  :root:not([data-theme]) { /* light-токены */ }
}
[data-theme="light"] { /* light-токены */ }
[data-theme="dark"]  { /* dark-токены */ }

// tailwind.config.js → colors ссылаются на переменные:
colors: { bg:'var(--bg)', surface:'var(--surface)', gold:'var(--gold)', ... }
