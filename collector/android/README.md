# Сборщик лобби на телефоне (adb + Haiku)

Замена десктопного сборщика: приложения живут на отдельном Android-телефоне, ПК только шлёт команды
по сети. Мышь и окна больше не нужны — проход не мешает работать за компьютером.

| Файл | Что делает |
|---|---|
| `Adb.ps1` | подключение к телефону, снимок экрана, тап, свайп, запуск приложения, состояние батареи |
| `Lobby.ps1` | проход по списку: страница → Haiku → свайп; склейка карточек, экспорт в JSON |
| `Run-Pass.ps1` | сценарий для Планировщика: PPPoker + X-Poker + Poker21, отправка в приёмник |

Отправка и формат снимка — общие с десктопом: `..\desktop\Send.ps1`, распознавание — `..\desktop\Haiku.ps1`.

## Что показал живой проход 26.09.2026

96 турниров из пяти клубов: PPPoker (Ginger, Go Daddy!, Private.G), X-Poker (GINGER+), Poker21
(Ginger21). Экраны телефона читаются лучше десктопных: крупнее шрифт, нет склейки иконки монеты
с цифрами. Дальше — правила, которые из этого прохода вышли и зашиты в скрипты.

1. **Координаты не нужны.** Единственное движение — свайп посреди экрана. Что написано на карточке,
   читает Haiku, поэтому смена вёрстки в приложении не ломает проход.
2. **Карточки не открываем.** Список отдаёт старт, имя, бай-ин, гарантию, игру и баунти — этого
   хватает для сверки с сеткой. Внутри карточки есть и детали (стек, уровни, ребаи, поздняя
   регистрация), но её открытие стоит 6–8 секунд на турнир — это отдельный проход по новинкам.
3. **Нижняя строка карточки крутится** (старт → гарантия → регистрация), поэтому на страницу
   PPPoker снимается три кадра, а непустые значения дополняют уже известную карточку.
4. **Приложения не перезапускаем.** X-Poker проверяет сеть только при старте и с VPN-выхода,
   попавшего в чёрный список, не поднимается вовсе; Suprema после `force-stop` требует ручного
   входа. Оба выводятся вперёд через `monkey`, но `am force-stop` к ним не применяется.
5. **Конец списка ловим по названиям.** Сравнивать кадры нельзя: в них тикают таймеры и счётчики
   игроков, поэтому один и тот же экран даёт разные картинки — проход уходил на пять лишних страниц.
6. **Системная «Назад» запрещена.** PPPoker показывает на неё «Exit the game?». Внутри приложений
   только их собственные стрелки.
7. **Промо поверх лобби** (привязка почты, карточка клуба, подсказки, лидерборд союза) закрывается
   крестиком; `Dismiss-PhoneOverlay` тыкает в известные места, если первая страница пришла пустой.
8. **Poker21 снимается в полном разрешении** — плитка в два столбца и мелкий шрифт.

Форматы у приложений разные: Poker21 пишет полную дату старта с годом, PPPoker и X-Poker — `MM/DD`,
Suprema — `DD/MM`. `ConvertTo-PhoneStart` разбирает все три (день больше 12 значит формат DD/MM).
Гарантию X-Poker прячет в название турнира («SHR MAGIC 800K» — 800 000 рублей, то есть 8 000 фишек).

## Сеть: VPN мешает и помогает одновременно

| Приложение | С туннелем | Напрямую |
|---|---|---|
| PPPoker | работает | работает |
| Poker21 | работает | работает |
| X-Poker | зависит от выхода: «risky network condition» на грязном адресе | не запускается |
| Suprema | виснет на заставке | загружается, но вход отваливается по таймауту |

Пока не настроена раздельная маршрутизация (Suprema мимо туннеля, остальные через него), Suprema
собирается отдельным проходом при выключенном VPN — X-Poker к тому моменту уже запущен, и смена
сети ему не мешает.

## Подготовка телефона

1. **Кабель — самый надёжный канал:** adb видит устройство сразу после любой перезагрузки, портов
   не существует. Беспроводной режим: Settings → Additional settings → Developer options →
   Wireless debugging, спарить один раз, дальше `Set-PhoneFixedPort` уводит adbd на постоянный 5555
   (до перезагрузки телефона). `Connect-Phone` сам перебирает сохранённый адрес, порт 5555, mDNS и кабель.
2. **Фиксированный IP** за телефоном на роутере.
3. **Экран:** автояркость выключить, тёмную тему зафиксировать, автоповорот выключить, размер шрифта
   и масштаб экрана — по умолчанию.
4. **Блокировку экрана снять** (или свайп): после перезагрузки проход не должен упираться в PIN.
5. **Питание:** телефон на зарядке; «оптимизация энергопотребления в режиме ожидания» выключена,
   иначе Wi-Fi засыпает и adb не достучится (телефон уже терялся именно так).
6. **Приложения:** оставить открытыми в лобби нужных клубов на вкладке турниров — PPPoker в Ginger,
   X-Poker в GINGER+ 2022497, Poker21 в Ginger21. Аккаунт сборщика везде один: `prohod`.
7. **Ключ Anthropic** — `%USERPROFILE%\.ginger\anthropic_key`, **токен сборщика** —
   `%USERPROFILE%\.ginger\collector_token` (оба кладёт Иван, в репозиторий не попадают).

## Запуск

```powershell
. .\collector\android\Lobby.ps1
Connect-Phone
$cards = Invoke-XpMttPassPhone -OutDir $env:TEMP\pass -KeepShots
$cards | Format-Table name, starts_at, buyin, guarantee
```

Боевой проход целиком, без отправки на прод:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\collector\android\Run-Pass.ps1 -NoSend -KeepShots
```

Планировщик: задача «Ginger phone collector», ежедневно 10:00 и 22:00, действие — тот же файл без
`-NoSend`. Сессия пользователя не нужна: окон на ПК больше нет, достаточно включённого компьютера.
Упавшее приложение не роняет остальные, но проход завершается с ошибкой — это и есть сигнал о
неудачном проходе для Планировщика.

## Сколько стоит

Кадр после сжатия до 1568 px — примерно 1 500 входных токенов Haiku, кадр Poker21 в полном
разрешении — около 3 500. Проход по трём приложениям это ~40 кадров, то есть 5–7 центов.
Два прохода в день ≈ **$4–5 в месяц**. `Get-HaikuSpend` показывает расход за сессию, `Run-Pass.ps1`
печатает его в конце лога.

Бесплатная альтернатива, если ключ не заводить: кадры складываются на диск и читаются глазами
(или через Claude Code), проход при этом остаётся тем же.
